* Settings

Personal Linux terminal and desktop environment configuration. Configuration
files are organized under =config/=, and =./reset.sh= is the installation
entrypoint. Rime configuration also supports macOS Squirrel and Windows Weasel.

** Quick Start

Preview the default installation:

#+begin_src sh
./reset.sh --dry-run
#+end_src

Install the default core configuration (top, zsh, Neovim, and tmux):

#+begin_src sh
./reset.sh
#+end_src

You can also install selected targets:

#+begin_src sh
./reset.sh nvim tmux
./reset.sh mycli imv
./reset.sh dwm
./reset.sh rime
#+end_src

See all available options and targets:

#+begin_src sh
./reset.sh --help
#+end_src

** Installation Behavior

- Scripts can be invoked from any working directory.
- Files whose contents and permissions are unchanged are skipped, making
  repeated runs safe.
- Before replacing an existing file, the installer moves it to
  =~/.local/state/settings-backups/<timestamp>/=.
- Rime uses a merge installation: additional existing files are preserved, and
  the entire destination directory is backed up before any changes.
- =core= and =all= include only top, zsh, Neovim, and tmux. They do not install
  desktop configuration, Rime, or system packages.

Use =--backup-dir DIR= to choose a backup directory for the current run.

** Rime: Windows, macOS, and Linux

=config/rime/= contains the shared Keytao schemas, dictionaries, Lua modules,
and OpenCC data. =weasel.custom.yaml= controls Windows appearance;
=squirrel.custom.yaml= controls macOS appearance. Each frontend reads its own
configuration, so these files can coexist.

On macOS, install Squirrel 1.0 or newer with Lua support, then run:

#+begin_src sh
./rime.sh --dry-run
./rime.sh
#+end_src

The installer detects macOS and merges files into =~/Library/Rime/=;
on Linux it uses =~/.local/share/fcitx5/rime/=. On WSL this is still the Linux
directory, not the Windows Weasel directory. For Windows, manually merge
=config/rime/= into Weasel's user directory (normally =%APPDATA%/Rime=).
Run the frontend's *Deploy / 重新部署* command after installation. The macOS
installer prints this reminder and does not launch Squirrel or run Makefiles.

The Mac theme uses the Windows base16 colors, 20-point text, vertical candidates,
inline preedit, and hidden candidate numbers. Install =LXGW WenKai Screen= to
match the Windows font; otherwise it falls back to PingFang. Both light and dark
mode use base16. The candidate panel uses 2-point border insets plus the 8-point
outer corner radius, 5-point candidate spacing, and a 5-point highlight corner
radius. A 1-point upward baseline offset adjusts optical text centering.
Spacing and transparency need visual verification on the Mac.
The configuration fixes the keyboard layout to ABC and initializes Terminal
and iTerm2 in ASCII mode. Other app-specific defaults remain Squirrel's defaults.

Keyboard checks on macOS:

- F4 opens the scheme menu; F7 toggles simplified/traditional Chinese. Use Fn
  or enable standard function keys if macOS intercepts them.
- Left Shift and Caps Lock retain the shared Rime behavior. Check macOS's
  Caps Lock input-source switching setting if it conflicts.
- Schemas keep their existing key bindings; the Control bindings in
  =default.custom.yaml= are not automatically imported by the Keytao schemas.
- The chord schema uses Squirrel's =chord_duration: 0.1= seconds; check chord
  timing with the actual Mac keyboard.

The Windows snapshot was compared on 2026-09-15. The three missing entries
(上工, 母上, 父上) are included in =keytao.user.dict.yaml=. This is a maintained
configuration snapshot, not an automatic or bidirectional sync. After changing
local dictionaries, copy the changes back to this repository explicitly.
Generated =build/= data, =installation.yaml=, =user.yaml=, and runtime user
databases are not part of this snapshot; keep each machine's own state.

Shared configuration fixes:

- The saved simplified/traditional option and default shortcuts now refer to
  =s2tw=, matching the schemes.
- The chord schema omits optional 630 hints, English conversion, and pinyin
  annotations whose =wxwprompt.json=, =EN2en.json=, and =pinyin.json= files and
  dictionaries are missing. Their switches and bindings were removed too.
  To restore them, supply the original OpenCC data and re-enable the filters.
- Reverse lookup remains in the chord schema's translators; its invalid
  duplicate entry in the filter list was removed.

** Repository Layout

#+begin_example
.
├── config/               # Configuration files grouped by application
│   ├── nvim/
│   ├── rime/
│   ├── tmux/
│   ├── x11/
│   └── ...
├── scripts/lib/          # Shared installer functions
├── tests/                # Regression tests using a temporary HOME
├── reset.sh              # Main entrypoint
└── {top,zsh,nvim,...}.sh # Compatibility entrypoints for existing usage
#+end_example

The following components are not installed by default:

- =ubuntu.sh=: installs system packages with apt and snap; requires sudo.
- =doom.sh=: installs Doom Emacs; it runs only when =config/doom/= exists.
- =config/suckless/=: source configuration and patches for dwm, st, and
  slstatus; apply these manually.
- =config/windows/=: Windows application configuration; copy it manually.

** Compatibility Entrypoints

=top.sh=, =zsh.sh=, =nvim.sh=, =tmux.sh=, and =rime.sh= remain available
and forward their arguments to =reset.sh=. For example:

#+begin_src sh
./nvim.sh --dry-run
#+end_src
